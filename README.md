# TRUSS

Single-page website for an independent international sourcing and procurement agent.

## Preview

Open `dist/index.html` in a browser, or serve `dist` with any static HTTP server.

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Visit `http://127.0.0.1:8080`.

## Deploy

Publish the contents of `dist/` to a static host. There is no build step, dependency installation or environment configuration.

Edit page content and direct WhatsApp messages in `dist/index.html`. The optional brief builds a WhatsApp message in the visitor’s browser through `dist/site.js`. The site itself does not collect or store form entries. The visitor reviews and sends the draft from WhatsApp.
